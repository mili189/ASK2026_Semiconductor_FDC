# 🥇 ASK2026 : 딥러닝 기반 반도체 장비 이상 탐지 알고리즘 구현

주제 : 딥러닝 모델을 활용하여 반도체 장비의 이상 데이터를 탐지하는 알고리즘 구현

현대 반도체 제조 공정은 수백 단계의 단위 공정을 거치며 구조적 복잡성과 공정 비용이 급증하고 있다. 특히 장비의 성능 열화나 고장은 품질 및 수율 저하로 직결되어 막대한 경제적 손실을 초래하므로, 실시간 데이터 로그 모니터링을 통한 선제적 불량 예측과 공정 개선이 필수적이다. 이상 탐지(Anomaly Detection, AD)는 웨이퍼 제조 과정에서 생성되는 시계열 센서 데이터를 실시간으로 수집하여 장비의 이상 동작을 감지하는 핵심 기술이다. 이상 동작은 주로 부품의 노후화나 공정 진행 중 가스 유량, 전력, 압력 등의 변수가 정상 범위를 벗어남으로써 발생한다. 이를 조기에 발견하고 조치함으로써 반도체 공정의 운영 효율을 극대화하고 품질 신뢰성을 확보할 수 있다.

- 저자 : 이성재, 용규순, 류병석, 김영균

  
## 1️⃣ 데이터셋
- LAM 9600 TCP Metal Etcher의 식각 공정 데이터 중 Machine State Dataset
- [11] B. M. Wise, et al., A comparison of principal component analysis, trilinear decomposition and parallel factor analysis for fault detection in a semiconductor etch process, Journal of Chemometrics, 13, 3, 379–396, 1999.
